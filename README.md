# Sthyra Portfolio

Standalone Next.js codebase for Sthyra's new portfolio experience.

## Routes

- `/portfolio`
- `/portfolio/trifecta-veranza`
- `/portfolio/tula-whisper-of-trees`
- `/portfolio/aadhya-serene`

The root route redirects to `/portfolio`. No other Sthyra site pages are included.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000/portfolio`.

## Production build

```bash
npm run build
npm start
```
